Associação NP

Benefícios ilustrativos para o projeto acadêmico:

  • Sem taxa de associação
  • Acesso a informações da Câmara
  • Convites para atividades comunitárias

Associação Bronze

Benefícios ilustrativos para o projeto acadêmico:

  • Informações e comunicados
  • Participação em eventos de networking
  • Acesso a oportunidades de capacitação

Associação Prata

Benefícios ilustrativos para o projeto acadêmico:

  • Benefícios do Bronze
  • Divulgação em espaços selecionados
  • Descontos em eventos e treinamentos

Associação Ouro

Benefícios ilustrativos para o projeto acadêmico:

  • Benefícios do Prata
  • Maior visibilidade institucional
  • Prioridade em oportunidades de destaque
